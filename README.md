# 🔗 URL Shortener – Frontend

A modern, responsive **React frontend** for a URL Shortener application.  
This project provides a clean UI for shortening URLs, viewing analytics, and managing shortened links, while communicating with a Spring Boot backend via REST APIs.

---

## ✨ Features

- 🔐 User authentication (Login / Register)
- ✂️ Shorten long URLs instantly
- 📊 View click analytics with charts
- 🧾 List and manage shortened URLs
- 🌐 Supports custom domains & subdomains
- 🎨 Clean and minimal UI
- ⚡ Fast and responsive React application

---

## 🛠 Tech Stack

- React (Vite)
- React Router DOM
- Context API
- Framer Motion
- Chart library for analytics
- Axios / Fetch API
- CSS / Tailwind / Custom styles
